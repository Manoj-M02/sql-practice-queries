
# SQL Practice Questions

This repository contains **20 beginner-friendly SQL practice queries** using an **Employee** table. The queries cover essential SQL concepts such as data retrieval, filtering, sorting, and pattern matching.

## Topics Covered

* SELECT
* WHERE
* DISTINCT
* ORDER BY
* BETWEEN
* LIKE
* AND / OR / NOT
* LIMIT

## Files

Each SQL query is stored in a separate `.sql` file with a descriptive name for easy understanding.

## Purpose

This repository is created for **SQL practice**, **DBMS lab exercises**, and **interview preparation**.

⭐ Feel free to explore, practice, and improve your SQL skills!
